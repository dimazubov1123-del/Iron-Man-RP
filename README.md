# IRON MAN RP

Интерактивная фанатская RP-система по вселенной Marvel. Игрок выступает в роли Тони Старка: начинает в лаборатории, выбирает броню, проходит процедуру надевания и переходит к интерфейсу шлема с голосовым помощником JARVIS.

## Версия 0.1.0 Pre-Alpha

### Уже реализовано
- Русскоязычный интерфейс лаборатории Stark Industries.
- Демонстрационная стилизованная визуализация брони Mark III.
- Последовательность надевания с этапами и переходом в Helmet HUD.
- HUD с показателями реактора, брони, высоты и скорости (пока демонстрационные значения).
- Голосовой вывод JARVIS через Speech Synthesis API.
- Распознавание русских голосовых команд через Web Speech API, если браузер поддерживает его.
- Адаптивная компоновка для мобильных и настольных экранов.

### Голосовые команды
- «Джарвис, проведи диагностику».
- «Проверь энергию реактора».
- «Открой интерфейс шлема».
- «Вернись в лабораторию».
- «Начни надевание костюма».

> Важно: это ранний интерфейсный прототип. 3D-модель брони, реальная физика полёта, полноценная AI-модель JARVIS и игровые сценарии пока не реализованы. Телеметрия демонстрационная.

## Запуск локально
Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Сборка:
```bash
npm run build
npm run preview
```

## Публикация через GitHub Pages
В настройках репозитория откройте **Settings → Pages**, выберите **GitHub Actions** как источник публикации. Workflow `.github/workflows/pages.yml` автоматически собирает проект и публикует его через GitHub Pages при обновлении ветки `main`.
