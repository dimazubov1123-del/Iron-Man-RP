# IRON MAN RP

Интерактивная фанатская RP-система по вселенной Marvel. Игрок выступает в роли Тони Старка: начинает в лаборатории, выбирает броню, проходит процедуру надевания и переходит к интерфейсу шлема с голосовым помощником JARVIS.

## Версия 0.2.0 Pre-Alpha

### Обновление интерфейса
- Переработана лаборатория Stark Industries: более детальная панель управления, витрина Mark III, статусы подсистем и адаптивная навигация.
- Обновлена CSS-визуализация брони Mark III: дополнительные элементы шлема, корпуса, конечностей, реактора и анимация сканирования.
- Добавлен отдельный экран автоматизированного надевания брони с восемью этапами, описаниями, прогрессом, текущим статусом и списком последовательности.
- Добавлены управление паузой, продолжением, переходом к следующему этапу и безопасным прерыванием процедуры.
- Добавлены окно отчёта диагностики и быстрый доступ к проверке систем.
- Улучшены панель JARVIS, телеметрия и адаптивная компоновка для мобильных экранов.
- Сохранены русские голосовые команды и голосовой вывод JARVIS через Web Speech API.

### Голосовые команды
- «Джарвис, проведи диагностику».
- «Проверь энергию реактора».
- «Открой интерфейс шлема».
- «Вернись в лабораторию».
- «Начни надевание костюма».

> Важно: это ранний интерфейсный прототип. Броня пока представлена CSS-визуализацией, а не полноценной 3D-моделью. Реальная физика полёта, полноценная AI-модель JARVIS и игровые сценарии пока не реализованы. Телеметрия демонстрационная.

## Запуск локально
Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Сборка:
```bash
npm run build
npm run preview
```

## Публикация через GitHub Pages
В настройках репозитория откройте **Settings → Pages**, выберите **GitHub Actions** как источник публикации. Workflow `.github/workflows/pages.yml` автоматически собирает проект и публикует его через GitHub Pages при обновлении ветки `main`.

## Технологии
React, TypeScript, Vite, Lucide React, Web Speech API, CSS animations.
