# IRON MAN RP

Фанатский интерактивный RP-проект по вселенной Marvel. Игрок находится в роли Тони Старка: исследует лабораторию, взаимодействует с бронёй Mark III, проходит процедуру оснащения и использует интерфейс шлема с голосовым помощником JARVIS.

## Версия 0.3.0 Pre-Alpha — переход на Three.js

- Старый карточный интерфейс лаборатории заменён полноэкранной кинематографичной сценой.
- Добавлена интерактивная 3D-сцена на Three.js: процедурная модель брони Mark III из отдельных геометрических элементов, металлические материалы, ARC Reactor, светящиеся глаза и детали брони.
- Добавлены вращение модели мышью/касанием, приближение колёсиком и ограничение камеры для удобного осмотра.
- Создана сцена лаборатории: платформа брони, кольцевые световые элементы, направленное освещение, отражённый свет, туман, технический пол и частицы.
- Процедура надевания теперь визуально собирает броню по этапам: ноги, руки, корпус, плечи и шлем.
- Сохранены голосовой вывод JARVIS, распознавание голосовых команд (при поддержке браузером), телеметрия и экран HUD.
- Переработана компоновка под мобильные экраны.

## Управление
- Перетаскивайте сцену мышью или пальцем, чтобы вращать камеру.
- Используйте колёсико или жест масштабирования для приближения.
- Нажмите «Начать надевание», чтобы запустить сборку брони.
- Во время сборки доступны пауза, продолжение, переход к следующему этапу и прерывание.
- Кнопка микрофона запускает голосовое управление, если браузер поддерживает Web Speech API.

## Технические ограничения текущей версии
Модель Mark III в версии 0.3.0 — процедурная 3D-модель из геометрии Three.js, а не точная скульптурная модель из фильма. Сцена и сборка интерактивны, но полноценные физика полёта, столкновения, реалистичная механика приводов, загрузка внешних моделей и ИИ-ассистент пока не реализованы. Показатели телеметрии демонстрационные.

## Локальный запуск
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Сборка и локальный просмотр:
```bash
npm run build
npm run preview
```

## GitHub Pages
В настройках репозитория выберите **Settings → Pages → GitHub Actions**. Workflow в `.github/workflows/pages.yml` собирает и публикует сайт при обновлении `main`.
